# E-commerce Customer & Purchase Analysis

Exploratory data analysis of customer and transaction data from an
e-commerce business, built with Python.

## Questions answered
- Average and minimum purchase values by country
- Spending by gender and product category
- Average spend per customer in a given market
- Revenue trends across years and product categories

## Free exploration
- Category performance table (revenue, orders, average value, share)
- Refunds by reason
- Patterns in discount use, refunds and year-over-year spend

## Tools
Python, pandas, NumPy, Matplotlib, seaborn, Jupyter Notebook

## Data
`customers.csv` and `transactions.csv` (not included in this repo).

## How to run
1. Place the two CSV files in a `data/` folder
2. Install dependencies: `pip install pandas numpy matplotlib seaborn`
3. Open `customer-purchase-analysis.ipynb` and run all cells
